# reference

## Зачем нужна папка

Эта папка хранит тематические справочные документы и обзоры.

## Что сюда класть

- описания систем, сервисов и компонентов;
- подтверждённые справочные заметки;
- материалы, к которым регулярно обращаются для сверки.

## Чего сюда не класть

- текущий рабочий план;
- журнал изменений сервисов;
- несортированные файлы без понятной темы.
