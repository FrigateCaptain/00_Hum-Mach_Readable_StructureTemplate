# inventories

## Зачем нужна папка

Эта папка нужна для перечней сущностей, ресурсов и объектов учёта.

## Что сюда класть

- списки серверов, сервисов, аккаунтов, доменов или других объектов;
- краткие карточки с предсказуемыми полями;
- ссылки на канонические документы по каждому объекту.

## Чего сюда не класть

- narrative-обзоры вместо реестров;
- рабочие задачи по изменению объектов;
- произвольные заметки без единого формата учёта.
