# README

## Зачем нужен файл

Этот файл даёт вход в справочную папку и объясняет, как в ней искать нужные материалы.

## Что сюда класть

- назначение хранилища;
- карту разделов `FACTS.md`, `reference/`, `inventories/`, `templates/`;
- правила навигации и обновления справочных материалов.

## Чего сюда не класть

- проектный план;
- backlog развития отдельного проекта;
- длинные операционные инструкции без привязки к разделам.
