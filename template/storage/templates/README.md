# templates

## Зачем нужна папка

Эта папка хранит заготовки документов и структур, которые можно переиспользовать.

## Что сюда класть

- шаблоны карточек, реестров и служебных документов;
- текстовые заготовки с пояснением по применению;
- минимальные образцы, которые ускоряют создание новых материалов.

## Чего сюда не класть

- реальные рабочие документы;
- уникальные данные конкретного проекта;
- шаблоны без объяснения, как и когда их использовать.
