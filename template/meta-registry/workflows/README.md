# workflows

## Зачем нужна папка

Эта папка хранит стандартизированные инструкции по сопровождению обзорного слоя и реестров.

## Что сюда класть

- workflow обновления реестров;
- workflow создания новой папки или типа;
- точки проверки синхронности между обзором и каноническими списками.

## Чего сюда не класть

- сами реестры;
- обзор всего workspace;
- задачи по отдельным проектам вне meta-уровня.
