# BACKLOG

## Зачем нужен файл

Этот файл хранит отложенные задачи по развитию обзорного слоя и системы реестров.

## Что сюда класть

- идеи по улучшению навигации workspace;
- отложенные вопросы по структуре реестров;
- темы для будущей стандартизации workflow и обзорных документов.

## Чего сюда не класть

- задачи отдельных проектов;
- канонические реестровые записи;
- текущий план изменения конкретной рабочей папки.
