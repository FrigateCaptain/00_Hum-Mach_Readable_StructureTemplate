# README

## Зачем нужен файл

Этот файл служит навигацией по мета-папке и объясняет, как устроен обзорный слой workspace.

## Что сюда класть

- карту `WORKSPACE_REVIEW.md`, `WORKSPACE_EXTERNAL_FOLDERS.md`, опциональных `DECISION_LOG.md` и `WORK_LOG.md`, `registries/`, `BACKLOG.md` и `workflows/`;
- правила маршрутизации к каноническим реестрам;
- ссылки на связанные обзорные документы.

## Чего сюда не класть

- полный реестр всех сущностей прямо в `README.md`;
- содержимое отдельных проектов;
- несвязанные операционные заметки без навигационной роли.
