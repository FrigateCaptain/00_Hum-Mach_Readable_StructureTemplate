# DECISION_LOG

**Опциональный слот.** Файл лежит в каркасе, чтобы место было предсказуемым. Живой журнал заводят, если в этой папке регулярно выбирают нормы. Если нет — при развёртывании файл можно не копировать.

## Зачем нужен файл

Журнал решений папки. Сюда кладут то, что могло быть иначе по воле владельца и дальше действует как норма.

## Что сюда класть

- выбор между вариантами: «выбрали A, отклонили B, дальше в FACTS такое-то значение»;
- норму, которая дальше действует, пока её не сменят новым решением;
- ссылку на место, куда записан актуальный итог (обычно `FACTS.md`).

Форма записи: прошедшее время выбора («выбрали», «отклонили», «норма такая-то»), не рассказ о работах.

## Чего сюда не класть

Работы: «создан файл», «перенесено в archive», «проверка выполнена». Это журнал работ (`WORK_LOG.md`).

Стоп-список глаголов и оборотов в этом файле: создан, создано, перенесено, вынесен, выполнено, проверка выполнена, актуализация выполнена.

## Перед записью

Два вопроса:

1. Это могло быть иначе по воле владельца и дальше действует как норма?
2. У события есть исполнитель и артефакт (файл, проверка, перенос)?

Только «да» на первый вопрос — запись только в `DECISION_LOG.md`.
Только «да» на второй — запись только в `WORK_LOG.md`.
Оба «да» — две разные формулировки, не один абзац в двух файлах.

## Пример

> Для папки, где слот заведён

**18 апреля 2026.** Выбрали хранить внешние корневые папки workspace отдельным файлом, отклонили перечисление их только в `WORKSPACE_REVIEW.md`. Дальше в FACTS: канон перечня внешних папок — `WORKSPACE_EXTERNAL_FOLDERS.md`.
