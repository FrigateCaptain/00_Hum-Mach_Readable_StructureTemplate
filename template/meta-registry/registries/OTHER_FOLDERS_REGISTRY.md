# OTHER_FOLDERS_REGISTRY

Канонический реестр папок, которые не относятся к основным типам (проект, процесс, хранилище, настройки/серверы, область).

## Зачем нужен файл

Отдельное место для классификации папок, не попавших в основные типы. Позволяет не терять из виду сущности, которые иначе остались бы «невидимыми» для реестров.

## Правила заполнения

| Поле | Что писать |
|------|------------|
| Имя папки | Устойчивое имя |
| Путь | Путь к папке |
| Описание | Кратко, что это за папка |
| Почему не основной тип | Почему это не проект, не процесс и не хранилище |
| Цель и смысл | Зачем папка существует |
| Статус | Активна / архив / эксперимент / служебная |
