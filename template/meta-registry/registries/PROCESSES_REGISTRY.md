# PROCESSES_REGISTRY

## Зачем нужен файл

Этот файл служит каноническим реестром процессных папок.

## Что сюда класть

- список процессов и их назначение;
- путь к каждой процессной папке;
- основные признаки процесса: владелец, частота или тип цикла.

## Чего сюда не класть

- проектные цели и roadmap;
- инструкции выполнения шагов процесса;
- разрозненные описания без реестрового формата.
