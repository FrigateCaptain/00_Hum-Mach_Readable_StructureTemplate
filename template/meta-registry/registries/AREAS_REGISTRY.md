# AREAS_REGISTRY

Канонический реестр областей workspace.

## Зачем нужен файл

Каноническое место для регистрации областей — сущностей, которые не являются ни проектами, ни процессами, ни хранилищами, но объединяют несколько связанных тем.

## Правила заполнения

| Поле | Что писать |
|------|------------|
| Имя области | Устойчивое имя области |
| Путь | Корневая папка или главный документ |
| Описание | Краткое описание предмета области |
| Цель выделения | Зачем область выделена отдельно |
| Границы и состав | Что входит в область и что не входит |
| Статус | Активна / в разработке / архив / зарезервирована |
