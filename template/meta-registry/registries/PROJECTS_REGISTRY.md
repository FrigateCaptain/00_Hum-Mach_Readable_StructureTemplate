# PROJECTS_REGISTRY

## Зачем нужен файл

Этот файл служит каноническим реестром проектных папок.

## Что сюда класть

- список проектов с кратким описанием роли;
- путь к каждой проектной папке;
- статус, владелец и ссылки на входные документы при необходимости.

## Чего сюда не класть

- детальный backlog проектов;
- narrative-обзоры вместо реестровых записей;
- дубли тех же записей в другой произвольной форме.
