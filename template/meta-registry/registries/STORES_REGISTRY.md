# STORES_REGISTRY

## Зачем нужен файл

Этот файл служит каноническим реестром справочных и storage-папок.

## Что сюда класть

- список хранилищ и справочников;
- путь к каждой папке;
- тип справочного содержания и назначение каждого раздела.

## Чего сюда не класть

- подробные технические факты из самих хранилищ;
- backlog-задачи по развитию инфраструктуры;
- смешанные записи, где невозможно понять тип папки.
