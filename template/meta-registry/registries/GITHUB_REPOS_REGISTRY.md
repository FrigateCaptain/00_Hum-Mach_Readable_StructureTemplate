# GITHUB_REPOS_REGISTRY

## Зачем нужен файл

Этот файл служит каноническим реестром публичных и связанных git-репозиториев.

## Что сюда класть

- имя репозитория и ссылку на него;
- путь к связанной локальной папке, если она есть;
- краткую роль репозитория в общей системе.

## Чего сюда не класть

- историю всех коммитов;
- приватные токены, ключи и секреты;
- длинные обзоры вместо кратких реестровых записей.
