# CONDITIONS_n_CONSTRAINTS

## Зачем нужен файл

Этот файл показывает рамки, в которых проект реально выполняется.

## Что сюда класть

- ограничения по времени, ресурсам и зависимостям;
- риски и внешние условия;
- обязательные условия, которые влияют на планирование.

## Чего сюда не класть

- целевое состояние проекта;
- канонические справочные факты без привязки к ограничениям;
- текущие шаги выполнения вместо `PLAN.md`.
