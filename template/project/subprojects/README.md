# subprojects

## Зачем нужна папка

Эта папка нужна, когда внутри проекта появляется самостоятельный контур работ.

## Что сюда класть

- подпроекты со своим `README.md`, `PLAN.md` и другими ключевыми файлами;
- ссылки на связь подпроекта с родительским проектом;
- только те подпапки, у которых есть отдельная цель и рамка.

## Чего сюда не класть

- случайные тематические подборки файлов;
- workflow-инструкции без отдельной проектной цели;
- всё подряд, что не поместилось в корне проекта.
