# workflows

## Зачем нужна папка

Эта папка хранит повторяемые пошаговые инструкции внутри проекта.

## Что сюда класть

- workflow-документы с шагами выполнения;
- условия запуска и точки проверки;
- ожидаемый результат каждой инструкции.

## Чего сюда не класть

- описание всего проекта целиком;
- список проектных целей;
- backlog-идеи без пошаговой процедуры.
