# VALUABLE_FINDINGS_REGISTRY

**Опциональный слот.** Заводить, когда нужен список: какие материалы просмотрены и какую мысль из них оставляют. Имя файла в шаблоне — каноническое: `VALUABLE_FINDINGS_REGISTRY.md`. Слот есть у project, process, groundwork и storage.

## Зачем нужен файл

Реестр ценного по итогам изучения (registry of valuable findings). В нём два слоя: что просмотрено и изучено, и что из этого оставляют как ценное.

## Что сюда класть

- какие материалы просмотрены и изучены, и где лежит каждый;
- по каждому предмету — мысль, которую стоит сохранить. Мысль пишется так, чтобы её понял человек, который сам материал не открывал. Рядом — откуда она взята.

## Чего сюда не класть

- рабочий механизм, скрипт или приём, который переносят в дело. Для этого служат наработки groundwork, `CATALOG.md` и `RELEVANT_GROUNDWORK.md`;
- канонические факты папки (`FACTS.md`);
- решения, которые могли быть иначе (`DECISION_LOG.md`);
- отложенные задачи (`BACKLOG.md`).

## Пример

> Разобрали внешний репозиторий.

**Просмотрено.** Обзор репозитория и статья по нему. Файлы лежат в папке исследования.

**Ценное.** Как README ставит задачу. Какой перечень частей README называет.
