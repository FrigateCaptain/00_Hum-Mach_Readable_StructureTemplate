# RELEVANT_GROUNDWORK

## Зачем нужен файл

Локальный указатель: какие наработки из папки типа **groundwork** важны именно для этой папки. Discoverability без копирования текстов how-to.

## Что сюда класть

- ссылки только на релевантные файлы groundwork: индексы (`INDEXES/`), сквозные обзоры (`crosscutting/`), при необходимости строку/раздел `CATALOG.md`;
- короткое пояснение, зачем ссылка нужна этой папке.

## Чего сюда не класть

- полные копии обзоров;
- доменные каноны этой же папки (FACTS, workflows) — они и так здесь;
- ссылки «на всякий случай» без связи с текущей работой;
- абсолютные пути конкретной машины и имена чужих внутренних store.

---

## Пример

> Для проекта «Публикация обучающего курса по структуре workspace»

**Назначение в этом проекте:** быстро открыть сквозные практики версионирования документов и указатель по текстам/файлам — без дублирования в `FACTS.md`.
