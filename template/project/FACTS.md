# FACTS

## Зачем нужен файл

Этот файл служит каноническим местом для устойчивых фактов проекта.

## Что сюда класть

- подтверждённые пути, URL, идентификаторы и параметры;
- принятые решения, которые нужно быстро сверять;
- определения, на которые ссылаются другие документы.

## Чего сюда не класть

- временные заметки и черновые гипотезы;
- пошаговый план работ;
- дубли тех же фактов в нескольких формулировках без необходимости.
