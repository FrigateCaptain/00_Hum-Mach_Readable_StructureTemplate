# README

## Зачем нужен файл

Этот файл даёт точку входа в проектную папку и быстро объясняет, что это за проект.

## Что сюда класть

- назначение проекта;
- текущий статус или фазу;
- ссылки на `CONTEXT.md`, `GOALS.md`, `PLAN.md`, `FACTS.md`, `DECISION_LOG.md`, `WORK_LOG.md` и другие ключевые документы.

## Чего сюда не класть

- полный backlog проекта;
- длинные списки фактов и технических параметров;
- пошаговые инструкции, которые должны жить в `workflows/`.
