# WORK_LOG

## Зачем нужен файл

Журнал работ папки. Сюда кладут то, у чего есть исполнитель и артефакт.

## Что сюда класть

- «создан файл X»;
- «проверено, что тег совпадает с CHANGELOG»;
- если решение уже было: «норма из DECISION_LOG за такую-то дату записана в FACTS».

Форма записи: сделанное действие и его артефакт, не формулировка выбора нормы.

## Чего сюда не класть

Решения: «утверждено», «решено», «принято». Это журнал решений (`DECISION_LOG.md`).

Стоп-список глаголов и оборотов в этом файле: утверждено, решено, принято.

## Перед записью

Два вопроса:

1. Это могло быть иначе по воле владельца и дальше действует как норма?
2. У события есть исполнитель и артефакт (файл, проверка, перенос)?

Только «да» на первый вопрос — запись только в `DECISION_LOG.md`.
Только «да» на второй — запись только в `WORK_LOG.md`.
Оба «да» — две разные формулировки, не один абзац в двух файлах.
