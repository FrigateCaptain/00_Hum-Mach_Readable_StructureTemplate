# BACKLOG

## Зачем нужен файл

Этот файл хранит задачи и вопросы, которые сознательно отложены.

## Что сюда класть

- идеи для следующих итераций;
- темы вне текущего плана;
- open issues, к которым нужно вернуться позже.

## Чего сюда не класть

- задачи текущего спринта или активной фазы;
- канонические факты;
- историю возникновения проекта вместо `CONTEXT.md`.
