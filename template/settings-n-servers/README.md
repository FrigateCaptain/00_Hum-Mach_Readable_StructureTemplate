# README

## Зачем нужен файл

Этот файл даёт вход в папку конфигураций и серверной документации и объясняет, как в ней искать нужные материалы.

## Что сюда класть

- назначение папки (какие серверы, сервисы и конфигурации здесь документируются);
- карту разделов `FACTS.md`, `SERVICE_CHANGES_LOG.md`, `INCIDENTS.md`, `reference/`, `inventories/`;
- правила навигации и обновления серверной документации.

## Чего сюда не класть

- проектный план;
- backlog развития отдельного проекта;
- справочные материалы общего характера, не связанные с инфраструктурой.
