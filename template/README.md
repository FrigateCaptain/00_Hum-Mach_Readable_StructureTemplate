# Физический шаблон

Эта папка материализует набор типов из `STRUCTURE_GUIDE.md`.

## Что здесь лежит

- `project/` — шаблон папки, у которой есть цель, ограничения, план и накапливаемые факты.
- `process/` — шаблон папки для повторяемой деятельности и рабочих циклов.
- `storage/` — шаблон папки для справочных материалов и канонических сведений.
- `settings-n-servers/` — шаблон папки для конфигураций, серверов, VPN и инфраструктурной документации.
- `meta-registry/` — шаблон обзорного слоя и канонических реестров workspace.

## Как использовать

- Копируйте только подходящий тип, а не всё дерево целиком.
- Адаптируйте состав файлов под роль папки, сохраняя разделение по типам содержания.
- Проверяйте синхронность с `../STRUCTURE_GUIDE.md`, если расширяете шаблон.

## Чего здесь не делать

- Не воспринимать эту папку как единственную обязательную структуру для всех случаев.
- Не заполнять шаблон реальными секретами, адресами, токенами и production-данными.
- Не смешивать файлы разных ролей в один универсальный документ.
