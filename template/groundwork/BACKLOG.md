# BACKLOG

## Зачем нужен файл

Идеи и улучшения самой системы groundwork, которые не вошли в текущий фокус.

## Что сюда класть

- предложения по автоматизации каталога;
- вопросы классификации («домен vs crosscutting»);
- отложенные указатели и обзоры.

## Чего сюда не класть

- активные задачи текущего прохода по каталогу;
- сами наработки (их место — канон, `crosscutting/` или `_inbox/`);
- дубли строк из `CATALOG.md`.
