# INDEXES — указатели по темам

## Зачем нужна папка

Тематические указатели (maps of content): списки ссылок на каноны и сквозные обзоры по теме. Не заменяют `CATALOG.md`, а помогают browse по предмету.

## Что сюда класть

- файлы-указатели по устойчивым темам (`audio_video.md`, `texts_and_files.md`, …);
- в каждом указателе — короткое введение и таблица/список ссылок с путём канона.

## Чего сюда не класть

- полные тексты how-to;
- черновики без темы (им место в `_inbox/`);
- доменный канон целиком (оставьте у владельца, здесь — ссылка).

---

## Пример файла `audio_video.md`

```markdown
# Указатель: аудио и видео

Краткий вход в наработки по записи, транскрипции и публикации.

| Тема | Где канон | Примечание |
|------|----------|------------|
| Пакетная транскрипция | `34_videos/skills-and-workflows/batch-audio-transcription/` | domain |
| Таймкоды для публикации | `groundwork/crosscutting/overview_publish_timecodes.md` | crosscutting |
```
