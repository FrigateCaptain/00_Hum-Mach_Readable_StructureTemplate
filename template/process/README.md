# README

## Зачем нужен файл

Этот файл даёт вход в процессную папку и объясняет, какую регулярную деятельность она описывает.

## Что сюда класть

- назначение процесса;
- частоту или триггеры выполнения;
- ссылки на `CONTEXT.md`, `PLAN.md`, `FACTS.md`, `BACKLOG.md` и `workflows/`.

## Чего сюда не класть

- проектные цели и roadmap, если это уже отдельный проект;
- канонические факты в несистемном виде;
- длинные инструкции вместо отдельных workflow-файлов.
