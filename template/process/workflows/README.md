# workflows

## Зачем нужна папка

Эта папка нужна для конкретных инструкций по выполнению повторяемых операций процесса.

## Что сюда класть

- пошаговые сценарии выполнения;
- условия запуска и критерии завершения;
- контрольные точки и ожидаемый результат.

## Чего сюда не класть

- общий обзор процесса;
- список устойчивых фактов;
- несвязанные заметки без процедурной ценности.
