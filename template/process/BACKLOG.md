# BACKLOG

## Зачем нужен файл

Этот файл хранит идеи и улучшения процесса, которые не вошли в текущий фокус.

## Что сюда класть

- предложения по автоматизации;
- вопросы для будущей проработки;
- отложенные улучшения и наблюдения.

## Чего сюда не класть

- активные задачи текущей итерации;
- стабильные правила процесса;
- описание проблемы без решения о её переносе в backlog.
