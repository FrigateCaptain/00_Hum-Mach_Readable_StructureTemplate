# RELEVANT_GROUNDWORK

## Зачем нужен файл

Локальный указатель: какие наработки из папки типа **groundwork** важны для этого процесса. Не заменяет `workflows/` процесса и не копирует каноны.

## Что сюда класть

- ссылки на индексы и сквозные обзоры groundwork, которые этот цикл реально использует;
- пометку, на каком этапе цикла ссылка нужна (если полезно).

## Чего сюда не класть

- полный dump каталога groundwork;
- операционные инструкции самого процесса (они в `workflows/` и `FACTS.md`);
- устаревшие ссылки без review.

> Для процесса «Дистрибуция правил ассистента»
