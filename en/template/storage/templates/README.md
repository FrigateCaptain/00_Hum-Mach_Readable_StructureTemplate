# templates

## Why this file exists

This folder stores document and structure stubs that can be reused.

## What belongs here

- templates for cards, registries, and working documents;
- text stubs with notes on how to apply them;
- minimal samples that speed up the creation of new materials.

## What does not belong here

- real working documents;
- unique data from a specific project;
- templates with no explanation of how and when to use them.
