# README

## Why this file exists

This file is the navigation for the meta folder and explains how the workspace overview layer is organized.

## What belongs here

- a map of `WORKSPACE_REVIEW.md`, `WORKSPACE_EXTERNAL_FOLDERS.md`, optional `DECISION_LOG.md` and `WORK_LOG.md`, `registries/`, `BACKLOG.md`, and `workflows/`;
- routing rules to the canonical registries;
- links to related overview documents.

## What does not belong here

- a full registry of every entity directly in `README.md`;
- the contents of individual projects;
- unrelated operational notes with no navigational role.
