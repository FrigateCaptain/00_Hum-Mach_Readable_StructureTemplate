# STORES_REGISTRY

## Why this file exists

This file is the canonical registry of reference and storage folders.

## What belongs here

- a list of stores and reference collections;
- the path to each folder;
- the type of reference content and the purpose of each section.

## What does not belong here

- detailed technical facts from the stores themselves;
- backlog tasks for developing infrastructure;
- mixed entries where the folder type cannot be identified.
