# OTHER_FOLDERS_REGISTRY

Canonical registry of folders that do not belong to the primary types (project, process, store, settings/servers, area).

## Why this file exists

A separate place to classify folders that did not fit the primary types. It keeps entities in view that would otherwise stay “invisible” to the registries.

## How to fill this registry

| Field | What to enter |
|------|------------|
| Folder name | A stable name |
| Path | Path to the folder |
| Description | Briefly, what this folder is |
| Why not a primary type | Why this is not a project, not a process, and not a store |
| Purpose and meaning | Why the folder exists |
| Status | Active / archive / experiment / utility |
