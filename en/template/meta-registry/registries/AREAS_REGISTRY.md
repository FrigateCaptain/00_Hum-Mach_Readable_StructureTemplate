# AREAS_REGISTRY

Canonical registry of workspace areas.

## Why this file exists

The canonical place to register areas — entities that are neither projects, nor processes, nor stores, but that group several related topics.

## How to fill this registry

| Field | What to enter |
|------|------------|
| Area name | A stable name for the area |
| Path | The root folder or the main document |
| Description | A short description of the area's subject |
| Why it is separate | Why the area is split out on its own |
| Boundaries and contents | What is in the area and what is not |
| Status | Active / in development / archive / reserved |
