# PROJECTS_REGISTRY

## Why this file exists

This file is the canonical registry of project folders.

## What belongs here

- a list of projects with a short description of each role;
- the path to each project folder;
- status, owner, and links to entry-point documents when needed.

## What does not belong here

- a detailed project backlog;
- narrative overviews in place of registry entries;
- duplicates of the same entries in some other ad-hoc form.
