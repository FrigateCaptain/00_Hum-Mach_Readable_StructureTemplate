# GITHUB_REPOS_REGISTRY

## Why this file exists

This file is the canonical registry of public and related git repositories.

## What belongs here

- the repository name and a link to it;
- the path to the related local folder, if there is one;
- a short description of the repository's role in the overall system.

## What does not belong here

- the history of every commit;
- private tokens, keys, and secrets;
- long overviews in place of short registry entries.
