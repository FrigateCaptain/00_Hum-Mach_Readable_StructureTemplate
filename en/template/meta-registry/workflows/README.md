# workflows

## Why this file exists

This folder stores standardized instructions for maintaining the overview layer and the registries.

## What belongs here

- a workflow for updating registries;
- a workflow for creating a new folder or type;
- checkpoints for keeping the overview in sync with the canonical lists.

## What does not belong here

- the registries themselves;
- an overview of the entire workspace;
- tasks for individual projects outside the meta layer.
