# VALUABLE_FINDINGS_REGISTRY

**Optional slot.** Start it when a list is needed: which materials were reviewed and which thought from them is kept. The file name in the template is the canonical one: `VALUABLE_FINDINGS_REGISTRY.md`. The slot exists for project, process, groundwork, and storage.

## Why this file exists

Registry of valuable findings. It has two layers: what was reviewed and studied, and what from that is kept as valuable.

## What to put here

- which materials were reviewed and studied, and where each one sits;
- for each subject, the thought worth keeping. Write the thought so that a person who has not opened the material can understand it. Next to it, say where it came from.

## What not to put here

- a working mechanism, a script, or a move that is carried into the job. Groundwork products, `CATALOG.md`, and `RELEVANT_GROUNDWORK.md` are for that;
- canonical facts of the folder (`FACTS.md`);
- decisions that could have been otherwise (`DECISION_LOG.md`);
- deferred tasks (`BACKLOG.md`).

---

## Example

> An outside repository was reviewed.

**Reviewed.** A review of the repository and an article about it. The files sit in the study folder.

**Valuable.** How the README states the task. Which list of parts the README names.
