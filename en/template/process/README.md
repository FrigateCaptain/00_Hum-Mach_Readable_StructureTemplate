# README

## Why this file exists

This file is the entry point to the process folder and explains what regular activity it describes.

## What belongs here

- the process's purpose;
- frequency or run triggers;
- links to `CONTEXT.md`, `PLAN.md`, `FACTS.md`, `DECISION_LOG.md`, `WORK_LOG.md`, `BACKLOG.md`, and `workflows/`;
- if the optional slots are in use — links to `CYCLE_LOG.md`, `VERSION_LOG.md`, `RELEASE_LOG.md`.

## What does not belong here

- project goals and a roadmap, if this is already a separate project;
- canonical facts in an unstructured form;
- long instructions instead of separate workflow files.
