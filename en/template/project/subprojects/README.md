# subprojects

## Why this folder exists

This folder is needed when a self-contained work loop appears inside the project.

## What belongs here

- subprojects with their own `README.md`, `PLAN.md`, and other key files;
- links that tie the subproject to the parent project;
- only those subfolders that have their own goal and bounds.

## What does not belong here

- ad-hoc topical collections of files;
- workflow instructions with no separate project goal;
- everything that did not fit in the project root.
