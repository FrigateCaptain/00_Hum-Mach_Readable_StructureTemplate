# BACKLOG

## Why this file exists

This file stores tasks and questions that have been deliberately deferred.

## What belongs here

- ideas for later iterations;
- topics outside the current plan;
- open issues to return to later.

## What does not belong here

- tasks of the current sprint or active phase;
- canonical facts;
- the project's origin story instead of `CONTEXT.md`.
