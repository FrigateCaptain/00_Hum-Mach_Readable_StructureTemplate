# README

## Why this file exists

This file is the entry point to the project folder and quickly explains what the project is.

## What belongs here

- the project's purpose;
- the current status or phase;
- links to `CONTEXT.md`, `GOALS.md`, `PLAN.md`, `FACTS.md`, `DECISION_LOG.md`, `WORK_LOG.md`, and other key documents.

## What does not belong here

- the project's full backlog;
- long lists of facts and technical parameters;
- step-by-step instructions that belong in `workflows/`.
