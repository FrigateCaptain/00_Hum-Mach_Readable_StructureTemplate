# README

## Why this file exists

This file is the entry point to the configurations and server-documentation folder and explains how to find materials in it.

## What belongs here

- the folder's purpose (which servers, services, and configurations are documented here);
- a map of the sections `FACTS.md`, optional `DECISION_LOG.md` and `WORK_LOG.md`, `SERVICE_CHANGES_LOG.md`, `INCIDENTS.md`, `reference/`, `inventories/`;
- rules for navigating and updating server documentation.

## What does not belong here

- a project plan;
- a backlog for developing a separate project;
- general-purpose reference materials with no tie to infrastructure.
